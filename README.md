## 📖 О программе

**Power Master Premium** — это стильная утилита для управления питанием компьютера с поддержкой:

- 🔴 **Выключение** — быстрое завершение работы.
- 🔄 **Перезагрузка** — с возможностью принудительного закрытия программ.
- 🌙 **Сон** — экономия энергии без потери данных.
- 💤 **Гибернация** — сохранение состояния на диск.
- 🔒 **Блокировка** — мгновенная защита экрана.

А также:

- ⏱️ **Таймер** — запланируйте действие через часы, минуты или секунды.
- 🔑 **Лицензирование** — привязка ключа к вашему ПК (HWID).
- 🔄 **Автообновление** — программа сама проверяет новые версии на GitHub.
- 🎨 **Две темы** — тёмная и светлая.
- 🚀 **Автозагрузка** — запуск в трее при старте Windows.
- 🛡️ **Защита триала** — счетчик запусков хранится на сервере.

## 🚀 Установка

### Вариант 1. Скачать готовый EXE (рекомендуется)

1. Перейдите в раздел [**Releases**](https://github.com/voroshilov64221-beep/PowerMaster/releases).
2. Скачайте последний `PowerMaster.exe`.
3. Запустите от имени администратора (UAC).
